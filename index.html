Load your local draft index

Draft Room never ships match data. Build the index from your clone of the official GRID data, then load it here: it stays in this browser.

git clone https://github.com/cloud9esports/stl-hackathon-2026-grid-starter.git
node tools/build-index.mjs --data ../stl-hackathon-2026-grid-starter   # writes .local/index.json
node serve.mjs                                                        # opens with the index loaded

Or press Load draft index and pick .local/index.json. The Fearless series board works without data too.
